# realstate-sak

Website for **Sakha Consultancy** — Real Estate | Investment | Finance.

Laravel 12 · Inertia.js v3 · Vue 3 · Tailwind CSS v4 · Vite

```bash
composer install && npm install
cp .env.example .env && php artisan key:generate
php artisan migrate
composer run dev
```

See [`workflow.md`](workflow.md) for project structure, conventions and the change log.
